# Project cover art — sources and licenses

These images are bundled with Checkmark Workspace as default project covers
until a project has its own `cover_url`. They were cropped to a 3:4 portrait
and saved as optimized WebP. Originals remain the photographers' work.

All photos are used under a license that allows this (Unsplash License or
the Pexels License). Attribution is not required by those licenses, but the
photographers are credited here whenever the source could be confirmed.
